# My Portfolio by miandrs

## Installation

1. Open a terminal, then clone the project:

   ```bash
   git clone https://github.com/miandrs/portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd portfolio
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the server:
   ```bash
   ng serve
   ```
